## 📅 Daily Progress

The `daily-progress/` folder contains one learning log per day.

Each daily entry can include:
- What I learned
- What I practiced
- Code or notebook links
- Problems I solved
- What I will learn next

## 📆 Weekly Progress

The `weekly-progress/` folder contains short weekly summaries and milestones.

## ⚙️ Automation

A GitHub Actions workflow creates a daily progress template automatically. You can then replace the placeholder with your real learning notes.

> The automation is meant to keep the learning journal organized. The meaningful part is the actual work you add to the repository.

## 🎯 Goal

Build a public, organized record of my Data Science learning journey — from fundamentals to real-world projects.
